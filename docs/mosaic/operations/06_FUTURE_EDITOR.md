# Future Visual Layout Editor

## Not part of the MVP

An administration tool may be added later if the Mosaic grows.

## Minimum functionality

- load unplaced scenarios;
- show free/occupied slots;
- drag and drop a scenario into a slot;
- instant preview;
- save to `mosaic-layout.json` or create a PR;
- validate collisions/duplicates.

## Principle

The editor must not automatically “optimize” the map. It should remain a **human composition tool**.

## Governance

A layout change is a versioned editorial change, reviewable in Git.
