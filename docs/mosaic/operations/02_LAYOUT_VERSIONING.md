# Layout Versioning

## Files

`mosaic-layout-v1.json`, then optionally `mosaic-layout-v2.json`.

## When to create v2

- substantial growth (for example 120 → 160+);
- major art-direction change;
- need for new groups/negative space;
- page redesign.

## Compatibility

Scenario IDs remain stable. Changing layout must never change URLs.

## Changelog

Document:

- moved cells;
- new slots;
- new scenarios;
- editorial reasons.

## Visual memory

Avoid frequent relayouts: returning visitors may develop an approximate spatial memory of the mosaic.
