# MVP Acceptance Criteria

## Content

- [ ] 120 scenarios available;
- [ ] 120 unique titles;
- [ ] 120 preview summaries;
- [ ] 120 static pages;
- [ ] images/alt text compliant, or placeholders explicitly accepted.

## Mosaic

- [ ] all cells visible;
- [ ] no unintended overlap;
- [ ] identical layout after reload;
- [ ] responsive SVG;
- [ ] reserved slots remain invisible.

## Desktop

- [ ] hover updates the panel with perceived latency under 150 ms;
- [ ] click opens the correct scenario;
- [ ] keyboard focus works;
- [ ] focus is visible.

## Mobile

- [ ] tap selects;
- [ ] CTA opens;
- [ ] no dependency on hover;
- [ ] adequate touch targets.

## Accessibility

- [ ] keyboard navigation;
- [ ] ARIA labels;
- [ ] list view;
- [ ] reduced motion;
- [ ] contrast checked.

## Performance

- [ ] do not load all 120 images initially;
- [ ] no unnecessary UI framework;
- [ ] no backend request on initial page load;
- [ ] scenario links remain usable without JavaScript.
