# Editorial QA Checklist

For every scenario:

- [ ] concrete title;
- [ ] summary understandable without knowing Koali;
- [ ] 35–70 words;
- [ ] explains what Koali connects;
- [ ] does not claim to replace a specialized system;
- [ ] palette limited to useful verbs;
- [ ] plausible intensity values;
- [ ] maximum 3 preview badges;
- [ ] coherent image;
- [ ] descriptive alt text;
- [ ] full page reviewed;
- [ ] status/claim consistent with the source corpus.
