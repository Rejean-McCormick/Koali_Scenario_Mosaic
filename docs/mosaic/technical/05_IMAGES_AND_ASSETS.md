# Images and Assets

## Preview images

One image per scenario, ideally with a coherent visual style.

Recommendation:

- high-quality source;
- target crop 16:9 or 4:3;
- typical preview display width 480–640 px;
- descriptive alt text;
- no essential text embedded in the image.

## Astro assets

Storing images under `src/content/...` allows Astro to import and optimize them. Images in `public/` are served as-is.

## Lazy loading

Do not load all 120 images on first paint.

Approaches:

1. render only one initial image and change `src` on preview;
2. preload on hover/focus;
3. rely on normal browser caching.

## Placeholders

The panel must keep its dimensions while the image is loading. Use a neutral background and fixed aspect ratio to avoid CLS.

## Formats

Use AVIF/WebP when generated by the Astro image pipeline; keep a suitable original source in the repository when licensing permits.
