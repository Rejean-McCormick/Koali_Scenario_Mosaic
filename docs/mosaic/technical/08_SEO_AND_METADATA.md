# SEO and Metadata

## Mosaic page

- clear `<title>`;
- description explaining the 120 scenarios;
- real HTML text above/below the mosaic;
- link to list view.

## Scenario pages

Every scenario gets:

- unique title;
- meta description based on `preview_summary`;
- canonical URL;
- Open Graph image;
- unique H1;
- Markdown rendered as HTML.

## Sitemap

Astro can generate a sitemap through its official integration if desired.

## Sharing

Scenario URLs must remain stable so users can directly share the case they discovered in the mosaic.
