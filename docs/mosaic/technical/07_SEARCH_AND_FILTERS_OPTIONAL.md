# Search and Filters — Optional

## Product position

The mosaic is the primary experience. Search and filters must not turn it into a dashboard.

## MVP+

Add a field: **Search for a use case…**

Search can run against a small JSON index generated at build time:

- title;
- summary;
- palette;
- badges;
- domains.

## Effect

Matching cells remain bright; others fade.

## Advanced filters

Hide them behind **Explore by theme**.

## No external search engine

120 entries do not justify Algolia/Elastic initially. A normalized local search is sufficient.
