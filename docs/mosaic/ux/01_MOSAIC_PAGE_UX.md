# Mosaic Page UX

## Experience principle

The page should invite wandering. Visitors do not need to understand why cells are positioned where they are.

The priority is:

> **curiosity → micro-discovery → next cell → possible click.**

## Top panel

The panel should keep a stable size to avoid layout jumps.

### Idle state

- title: **Explore 120 ways to use Koali**;
- short subtitle;
- instruction: **Hover over a cell**;
- optional generic image or illustration.

### Scenario state

- 16:9 or 4:3 image;
- title;
- 35–70 word summary;
- 3–6 palette verbs;
- four component indicators;
- 0–3 badges;
- CTA: **View scenario**.

## Attention budget

The preview should be readable in 10–30 seconds.

Do not show in the preview:

- all metadata;
- canonical references;
- layout rationale;
- long technical description;
- 12 badges;
- detailed evidence status unless necessary.

## Hover

Response should feel immediate. An 80–150 ms transition is enough.

Hover must not trigger navigation or heavy animation.

## Local focus

On hover:

- active cell grows slightly;
- contrast increases;
- inactive cells may fade slightly if visually pleasing;
- no graph lines in the MVP.

## “Surprise me”

Recommended after the base MVP: select a random scenario and show it in the preview. Particularly useful for a general-public experience.
