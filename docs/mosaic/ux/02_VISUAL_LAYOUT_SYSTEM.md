# Mosaic Visual System

## Overall shape

Free-form and composed. Do not force a giant hexagon if it hurts the composition.

## Cell shape

The hexagon is recommended as a subtle Koali visual motif, but it is not a functional requirement. A cell can be a regular hexagon with a slightly larger interactive hit area than its visible surface.

## Rhythm

The mosaic may contain:

- dense areas;
- breathing room;
- small clusters;
- a few slightly larger hero cells;
- an irregular outer edge.

The goal is a living composition, not a mathematical grid.

## Color

Color may reflect the dominant category/palette, but users do not need to learn the legend.

Rules:

- harmonized palette;
- moderate saturation at rest;
- stronger saturation/contrast on hover;
- never encode information only through color;
- maintain sufficient contrast against the background.

## Size

Avoid using size to imply real-world importance. If some cells are larger, they should mean **hero scenario / editorial landmark**.

## SVG viewBox

A base such as `0 0 1440 900` is appropriate. CSS then makes the SVG responsive.
