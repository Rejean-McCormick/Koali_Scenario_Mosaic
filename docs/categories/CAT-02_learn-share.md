# CAT-02 — Learn & Share

Turn knowledge and practice into learning that can move between people, teams, places, and generations.

## Why this category exists

This is a human entry point, not a software module. It becomes characteristically Koali when the activity must remain connected to the people, decisions, work, evidence, or memory that follow.
