# Source basis and editorial boundaries

This English pack is an **editorial presentation layer** built from the Koali materials supplied in the conversation (including earlier source documents that used the kOA name) and from the v2 usage corpus. It is not itself a new source of technical authority.

## Source hierarchy used for presentation

1. Koali capability / possibility canon supplied with the project.
2. Earlier ecosystem documents describing the knowledge-to-action architecture, including materials that used the kOA name.
3. UCKK canon and UCKK-Moodle documentation for educational, media, archive, standalone, and Konnaxion-connected boundaries.
4. Scenario and use-example material supplied by the project.
5. Editorial derivation in this pack, clearly marked through `derivation` and `runtime_evidence`.

## Important boundary

The source corpus does not automatically prove that every scenario in the Atlas is implemented end to end. The Atlas demonstrates **architectural composition and intended versatility**. Runtime claims require separate evidence.

## Terminology

System names—Koali, Kristal, Konnaxion, Orgo, UCKK, EkoH, Smart Vote, SemantiK—are preserved. English descriptors in this pack are explanatory labels, not renamings of the canonical components.
