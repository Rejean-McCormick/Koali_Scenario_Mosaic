# SCN-009 — A simple experiment produces a result the textbook says is impossible

> **Universal pattern —** Move from a symptom, signal, or anomaly to structured understanding.

> **Pattern family —** `PAT-01` Investigate a signal

## Situation

A laboratory repeatedly obtains a result that conflicts with the accepted explanation. Instead of discarding it as error, the team precisely preserves the conditions, protocol deviations, and competing hypotheses.

## What is usually lost

Context, sources, and hypotheses scatter before a usable understanding can form.

## With Koali

Koali turns the anomaly into a research object: result, protocol, sources, critiques, and replications remain connected.

The Koali point is continuity: knowledge, people, decisions, work, and memory remain connected to the same context instead of being recreated in separate tools.

## Loop

`unexpected result → replication → parameters → literature → hypotheses → new tests`

## Usage palette

understand · verify · collaborate · remember

- **Kristal ●●●●●** — keeps the knowledge, provenance, relationships, and memory needed to understand the situation.

The value is not any one isolated feature. It is preserving the same context across **unexpected result → … → new tests** so knowledge, people, choices, work, and memory remain connected.
