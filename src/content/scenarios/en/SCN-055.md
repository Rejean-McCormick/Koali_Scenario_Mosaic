# SCN-055 — A pension fund must decide how many future decades it dares to model

> **Universal pattern —** Place options, criteria, evidence, and constraints side by side before choosing.

> **Pattern family —** `PAT-10` Compare and prioritize explicitly

## Situation

The portfolio must serve today's retirees and workers who will retire forty years from now. Inflation, climate, technology, and geopolitics make the scenarios radically different.

## What is usually lost

Evidence, arguments, disagreements, and reasons for a choice become detached from the decision and its consequences.

## With Koali

Kristal preserves the assumptions behind each scenario and their influence on allocation; future revisions can distinguish model error from a change in context.

The Koali point is continuity: knowledge, people, decisions, work, and memory remain connected to the same context instead of being recreated in separate tools.

## Loop

`objectives → horizons → scenarios → allocations → risks → decision → reevaluation`

## Usage palette

understand · deliberate · choose · remember

- **Kristal ●●●●○** — keeps the knowledge, provenance, relationships, and memory needed to understand the situation.

## What makes this characteristically Koali

The value is not any one isolated feature. It is preserving the same context across **objectives → … → reevaluation** so knowledge, people, choices, work, and memory remain connected.
