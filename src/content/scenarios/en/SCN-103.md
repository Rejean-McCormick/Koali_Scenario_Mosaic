# SCN-103 — A quality action cuts defects in half but creates a new problem six months later

> **Universal pattern —** Connect results, decisions, and causes into usable lessons learned.

> **Pattern family —** `PAT-19` Turn action into a lesson

## Situation

The initial dashboard said "success." The organization reopens the decision by connecting short-term effects, indirect consequences, and conditions that changed.

## What is usually lost

The result ends up in a report or in a few people’s memory instead of improving the next decision.

## With Koali

Koali preserves the chain between hypothesis, action, and results over time; an action can move from "successful" to "needs review" without erasing its history.

The Koali point is continuity: knowledge, people, decisions, work, and memory remain connected to the same context instead of being recreated in separate tools.

## Loop

`problem → action → metrics → side effects → reevaluation → adjustment`

## Usage palette

remember · verify · understand · act

## Component roles in this scenario

- **Kristal ●●●●●** — keeps the knowledge, provenance, relationships, and memory needed to understand the situation.
- **Konnaxion ●●○○○** — connects the people who can add, challenge, teach, learn, or interpret the shared context.
- **Orgo ●●●●●** — takes over when a check, decision, request, or intervention must become tracked work.

## What makes this characteristically Koali

The value is not any one isolated feature. It is preserving the same context across **problem → … → adjustment** so knowledge, people, choices, work, and memory remain connected.

## Transferable to

quality · policy · operations

The domain changes; the pattern remains: **Connect results, decisions, and causes into usable lessons learned.**
