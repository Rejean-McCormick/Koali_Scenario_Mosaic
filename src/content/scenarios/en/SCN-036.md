# SCN-036 — A film crew prepares a one-take sequence that no department can pull off alone

> **Universal pattern —** Keep needs, references, trade-offs, and versions connected throughout collective creation.

> **Pattern family —** `PAT-07` Co-create without losing the why

## Situation

Camera, lighting, stunts, set, sound, and acting must work to the second. Every local change creates consequences elsewhere, and the reason behind choices must remain visible throughout rehearsals.

## What is usually lost

Ideas, research, trade-offs, and deliverables become separated across tools and teams.

## With Koali

Koali connects creative choices, technical constraints, and responsibilities so a change never arrives as an instruction stripped of context.

The Koali point is continuity: knowledge, people, decisions, work, and memory remain connected to the same context instead of being recreated in separate tools.

## Loop

`vision → constraints → contributions → rehearsals → dependencies → final version → shoot`

## Usage palette

understand · collaborate · create · choose · organize

## Component roles in this scenario

- **Kristal ●●●○○** — keeps the knowledge, provenance, relationships, and memory needed to understand the situation.
- **Konnaxion ●●●●●** — connects the people who can add, challenge, teach, learn, or interpret the shared context.
- **Orgo ●●●●●** — takes over when a check, decision, request, or intervention must become tracked work.
- **UCKK ●○○○○** — supports learning and multimedia dissemination when the knowledge must reach a broader audience.

## What makes this characteristically Koali

The value is not any one isolated feature. It is preserving the same context across **vision → … → shoot** so knowledge, people, choices, work, and memory remain connected.

## Transferable to

film · live performance · complex operations

The domain changes; the pattern remains: **Keep needs, references, trade-offs, and versions connected throughout collective creation.**
