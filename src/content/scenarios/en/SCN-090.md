# SCN-090 — An Arctic team is stranded after its original plan collapses

> **Universal pattern —** Keep knowledge, roles, and work local, then synchronize without inventing success.

> **Pattern family —** `PAT-18` Keep working in field/offline mode

## Situation

Weather, energy, and mobility change while connectivity is intermittent. Members must continue documenting status, decisions, and resources locally, then reconcile their logs.

## What is usually lost

Reality changes faster than shared context, so teams risk acting on different or outdated information.

## With Koali

Koali preserves operational context on each device and can later resynchronize decisions and evidence without losing their local order.

The Koali point is continuity: knowledge, people, decisions, work, and memory remain connected to the same context instead of being recreated in separate tools.

## Loop

`disruption → local state → priorities → offline work → observations → synchronization → return`

## Usage palette

respond · organize · act · remember

## Component roles in this scenario

- **Kristal ●●●●●** — keeps the knowledge, provenance, relationships, and memory needed to understand the situation.
- **Konnaxion ●●●○○** — connects the people who can add, challenge, teach, learn, or interpret the shared context.
- **Orgo ●●●●●** — takes over when a check, decision, request, or intervention must become tracked work.

## What makes this characteristically Koali

The value is not any one isolated feature. It is preserving the same context across **disruption → … → return** so knowledge, people, choices, work, and memory remain connected.

## Transferable to

expeditions · field operations · remote regions

The domain changes; the pattern remains: **Keep knowledge, roles, and work local, then synchronize without inventing success.**
