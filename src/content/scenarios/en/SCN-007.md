# SCN-007 — A network goes down exactly when a local radio station starts transmitting

> **Universal pattern —** Move from a symptom, signal, or anomaly to structured understanding.

> **Pattern family —** `PAT-01` Investigate a signal

## Situation

An intermittent outage escapes conventional tools because it depends on an external condition the network team does not measure. Technicians, radio amateurs, and suppliers must connect their observations before the pattern becomes visible.

## What is usually lost

Context, sources, and hypotheses scatter before a usable understanding can form.

## With Koali

Koali brings technical telemetry together with human observations that seem anecdotal when viewed separately.

The Koali point is continuity: knowledge, people, decisions, work, and memory remain connected to the same context instead of being recreated in separate tools.

## Loop

`outage → timestamps → external context → correlations → experts → test → correction`
