# SCN-005 — One Unknown Blight, Two Gardens, 600 Kilometers Apart

> **Universal pattern —** Move from a symptom, signal, or anomaly to structured understanding.

> **Pattern family —** `PAT-01` Investigate a signal

## Situation

Northern growers see the same deformation appear on different plants. Some suspect a pathogen, others a new combination of weather, soil, and inputs; each person holds only a small part of the picture.

## What is usually lost

Each grower sees a symptom; nobody sees the weather-soil-input pattern across both gardens.

## With Koali

Koali aligns photos, weather, soil, and inputs across both sites, letting the group test a pattern without mistaking correlation for a diagnosis.

## Loop

`observations → geography → literature → local practices → hypotheses → sampling → understanding`
