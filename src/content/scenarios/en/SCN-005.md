# SCN-005 — Gardens 600 km apart develop the same unknown disease

> **Universal pattern —** Move from a symptom, signal, or anomaly to structured understanding.

> **Pattern family —** `PAT-01` Investigate a signal

## Situation

Northern growers see the same deformation appear on different plants. Some suspect a pathogen, others a new combination of weather, soil, and inputs; each person holds only a small part of the picture.

## What is usually lost

Context, sources, and hypotheses scatter before a usable understanding can form.

## With Koali

Koali connects local observations, photos, analyses, weather, cultivation practices, and literature without confusing correlation with causation.

The Koali point is continuity: knowledge, people, decisions, work, and memory remain connected to the same context instead of being recreated in separate tools.

## Loop

`observations → geography → literature → local practices → hypotheses → sampling → understanding`
