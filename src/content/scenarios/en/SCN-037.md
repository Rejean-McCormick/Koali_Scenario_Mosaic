# SCN-037 — After the Flood, Teenagers Build a Search Robot

> **Universal pattern —** Connect exploration, design, testing, decisions, and the next operational step.

> **Pattern family —** `PAT-09` Move an idea to a prototype

## Situation

The project starts as an emotional idea and gradually becomes mechanics, software, mapping, safety, testing, and data collection. Mentors join the team as new problems appear.

## What is usually lost

The emotional spark is lost as mechanics, code, safety, and testing split into separate project tracks.

## With Koali

Koali holds the original mission beside designs, mentors, and prototype dependencies, so technical maturity never erases the human reason for building it.

## Loop

`lived need → idea → capabilities → prototype → tests → failures → improvements → demonstration`

understand · collaborate · create · organize · verify

The value is not any one isolated feature. It is preserving the same context across **lived need → … → demonstration** so knowledge, people, choices, work, and memory remain connected.
