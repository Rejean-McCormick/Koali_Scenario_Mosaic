# SCN-120 — When a Source Changes, Find Every Video That Became Misleading

> **Universal pattern —** Connect published content, versions, and sources so it can be corrected, superseded, or revised.

> **Pattern family —** `PAT-24` Keep media aligned with knowledge

## Situation

The media is still online, but a source datum, rule, or recommendation has been revised. The system knows which derivative content could now mislead the public.

## What is usually lost

Old media keeps sounding authoritative after the source knowledge beneath it has changed.

## With Koali

Koali knows which media depend on that knowledge and routes them for warning, revision, regeneration, or withdrawal before yesterday’s truth misleads tomorrow’s audience.

## Loop

`source knowledge → derivative media → change → impact detection → revision → republication`

## Usage palette

remember · verify · disseminate

## What makes this characteristically Koali

The value is not any one isolated feature. It is preserving the same context across **source knowledge → … → republication** so knowledge, people, choices, work, and memory remain connected.
