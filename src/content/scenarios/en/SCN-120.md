# SCN-120 — An old video becomes suspect as soon as its source knowledge changes

> **Universal pattern —** Connect published content, versions, and sources so it can be corrected, superseded, or revised.

> **Pattern family —** `PAT-24` Keep media aligned with knowledge

## Situation

The media is still online, but a source datum, rule, or recommendation has been revised. The system knows which derivative content could now mislead the public.

## What is usually lost

Once published, content often becomes detached from its sources, versions, and the people able to update it.

## With Koali

Kristal maintains dependencies between facts and media; UCKK can flag, withdraw, regenerate, or route affected content for revision according to the publisher's rules.

The Koali point is continuity: knowledge, people, decisions, work, and memory remain connected to the same context instead of being recreated in separate tools.

## Loop

`source knowledge → derivative media → change → impact detection → revision → republication`

## Usage palette

remember · verify · disseminate

## Component roles in this scenario

- **Kristal ●●●●●** — keeps the knowledge, provenance, relationships, and memory needed to understand the situation.
- **Konnaxion ●●○○○** — connects the people who can add, challenge, teach, learn, or interpret the shared context.
- **Orgo ●●●○○** — takes over when a check, decision, request, or intervention must become tracked work.
- **UCKK ●●●●●** — supports learning and multimedia dissemination when the knowledge must reach a broader audience.

## What makes this characteristically Koali

The value is not any one isolated feature. It is preserving the same context across **source knowledge → … → republication** so knowledge, people, choices, work, and memory remain connected.

## Transferable to

media · training · documentation

The domain changes; the pattern remains: **Connect published content, versions, and sources so it can be corrected, superseded, or revised.**
