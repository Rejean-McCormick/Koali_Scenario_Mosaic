# SCN-022 — A child continues rehabilitation in a language the therapist does not speak

> **Universal pattern —** Preserve meaning and learning continuity when language, network access, or location changes.

> **Pattern family —** `PAT-06` Teach across language or connectivity constraints

## Situation

The professional designs exercises, but the family must be able to understand them, adapt them, and document what works at home, sometimes offline.

## What is usually lost

Knowledge stays attached to a person, document, or session and does not transfer well over time.

## With Koali

KonnectED and UCKK can deliver content adapted to the household and reconnect evidence of practice to the same learning path.

The Koali point is continuity: knowledge, people, decisions, work, and memory remain connected to the same context instead of being recreated in separate tools.

## Loop

`goal → exercises → language adaptation → practice → observations → adjustment`

## Usage palette

learn · teach-share · remember

## Component roles in this scenario

- **Kristal ●●●○○** — keeps the knowledge, provenance, relationships, and memory needed to understand the situation.
- **Konnaxion ●●●○○** — connects the people who can add, challenge, teach, learn, or interpret the shared context.
- **Orgo ●●●○○** — takes over when a check, decision, request, or intervention must become tracked work.
- **UCKK ●○○○○** — supports learning and multimedia dissemination when the knowledge must reach a broader audience.

## What makes this characteristically Koali

The value is not any one isolated feature. It is preserving the same context across **goal → … → adjustment** so knowledge, people, choices, work, and memory remain connected.

## Transferable to

rehabilitation · special education · family learning

The domain changes; the pattern remains: **Preserve meaning and learning continuity when language, network access, or location changes.**
