# SCN-045 — The Species Moves Faster Than the Borders

> **Universal pattern —** Connect exploration, design, testing, decisions, and the next operational step.

> **Pattern family —** `PAT-09` Move an idea to a prototype

## Situation

Biologists, landowners, communities, and governments must imagine a corridor that does not yet exist. Climate data changes while the plan is being built.

## What is usually lost

A corridor plan loses legitimacy when models, land constraints, promises, and earlier trade-offs separate.

## With Koali

Koali holds models, land realities, promises, and past trade-offs in one evolving case, allowing the route to adapt without sacrificing its legitimacy.

## Loop

`species → projections → territories → stakeholders → options → corridor prototype → adaptation`

understand · collaborate · create · deliberate · organize

The value is not any one isolated feature. It is preserving the same context across **species → … → adaptation** so knowledge, people, choices, work, and memory remain connected.
