# SCN-110 — One Emergency Alert, Eight Languages, Every Format

> **Universal pattern —** Render a knowledge base as courses, video, audio, guides, libraries, or channels.

> **Pattern family —** `PAT-23` Turn knowledge into media or learning

## Situation

The same instruction must remain consistent when translated, summarized, read aloud, or printed. If the source content changes, every affected derivative must be identified.

## What is usually lost

Eight translations drift into eight instructions when they depend on one pivot text instead of shared meaning.

## With Koali

Koali anchors every version to shared meaning rather than a pivot text, flagging affected variants when a concept changes without pretending all languages are equivalent.

## Loop

`source instruction → translations → formats → distribution → update → propagation`

## Usage palette

teach-share · disseminate · respond · verify

The value is not any one isolated feature. It is preserving the same context across **source instruction → … → propagation** so knowledge, people, choices, work, and memory remain connected.
