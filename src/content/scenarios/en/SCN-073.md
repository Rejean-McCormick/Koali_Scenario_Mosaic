# SCN-073 — Turn an Expressway into a Park While the City Keeps Moving

> **Universal pattern —** Turn an objective or project into tracked work and then into a verified result.

> **Pattern family —** `PAT-15` Carry a plan through execution

## Situation

The political decision is only the beginning. Transportation, businesses, emergency services, construction, communications, and temporary phases must translate an abstract intention into reality.

## What is usually lost

Construction can satisfy the schedule while quietly abandoning the public reasons the project was approved.

## With Koali

Koali turns the reasons for approval into checkpoints the project must satisfy, revealing drift before an on-time delivery replaces its civic purpose.

## Loop

`decision → objectives → phases → roles → dependencies → construction → measurements → adjustments`

## Usage palette

choose · organize · act · verify · remember

## What makes this characteristically Koali

The value is not any one isolated feature. It is preserving the same context across **decision → … → adjustments** so knowledge, people, choices, work, and memory remain connected.
