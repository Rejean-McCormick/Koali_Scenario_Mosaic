# SCN-117 — Show the Research That Is Disputed, Provisional, or Failed

> **Universal pattern —** Render a knowledge base as courses, video, audio, guides, libraries, or channels.

> **Pattern family —** `PAT-23` Turn knowledge into media or learning

## Situation

The public channel does not mix peer-reviewed articles, preprints, hypotheses, raw data, and popularization. Readers can move from simple media to the exact scientific status of what they are viewing.

## What is usually lost

A public channel flattens peer review, hypothesis, raw data, dispute, and failure into one status.

## With Koali

Koali carries confidence and source lineage into every public explanation, so corrections reach affected media and readers can see how much trust each claim deserves.

## Loop

`research → status → sources → media → public → critique → update`

## Usage palette

teach-share · disseminate · collaborate · learn

## Component roles in this scenario

- **Kristal ●●●●●** — keeps the knowledge, provenance, relationships, and memory needed to understand the situation.
- **Konnaxion ●●●●○** — connects the people who can add, challenge, teach, learn, or interpret the shared context.
- **Orgo ●○○○○** — takes over when a check, decision, request, or intervention must become tracked work.
- **UCKK ●●●●●** — supports learning and multimedia dissemination when the knowledge must reach a broader audience.

## What makes this characteristically Koali

The value is not any one isolated feature. It is preserving the same context across **research → … → update** so knowledge, people, choices, work, and memory remain connected.

## Transferable to

universities · open science · media

The domain changes; the pattern remains: **Render a knowledge base as courses, video, audio, guides, libraries, or channels.**
