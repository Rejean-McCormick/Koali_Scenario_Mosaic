# SCN-025 — Innu schools rehearse remotely all year, then meet in Pessamit to perform together

> **Universal pattern —** Preserve meaning and learning continuity when language, network access, or location changes.

> **Pattern family —** `PAT-06` Teach across language or connectivity constraints

## Situation

In KonnectED, students from several communities form complementary teams, rehearse their roles, and prepare a shared performance. Orgo distributes responsibilities for buses, lodging, permissions, meals, and equipment; one student then turns the travel plan into a song in Innu so everyone remembers the dates and stages.

## What is usually lost

Knowledge stays attached to a person, document, or session and does not transfer well over time.

## With Koali

The same context connects learning, collaboration, and logistics; plan updates can also flag when a learning artifact that has become inaccurate needs to be corrected.

The Koali point is continuity: knowledge, people, decisions, work, and memory remain connected to the same context instead of being recreated in separate tools.

## Loop

`talents → teams → rehearsals → travel → roles → confirmations → performance → memory`

## Usage palette

learn · teach-share · organize · remember

## What makes this characteristically Koali

The value is not any one isolated feature. It is preserving the same context across **talents → … → memory** so knowledge, people, choices, work, and memory remain connected.
