# SCN-063 — Students from several schools converge on Pessamit for a performance prepared remotely all year

> **Universal pattern —** Turn an objective or project into tracked work and then into a verified result.

> **Pattern family —** `PAT-15` Carry a plan through execution

## Situation

After months of rehearsals in KonnectED, the trip must become real: buses, schedules, lodging, permissions, meals, equipment, chaperones, and stage. Each person who accepts a role then confirms completion with the key information, and the plan takes shape in front of the group.

## What is usually lost

Work often arrives without the why, the right context, its dependencies, or the expected proof of result.

## With Koali

Orgo turns collective intent into tracked responsibilities; participants see the state of the plan and receive by default the notifications that are relevant to them or the ones they choose to follow.

The Koali point is continuity: knowledge, people, decisions, work, and memory remain connected to the same context instead of being recreated in separate tools.

## Loop

`project → roles → commitments → confirmations → dependencies → travel → performance`

## Usage palette

collaborate · organize · act · coordinate · remember

- **Kristal ●●●○○** — keeps the knowledge, provenance, relationships, and memory needed to understand the situation.

## What makes this characteristically Koali

The value is not any one isolated feature. It is preserving the same context across **project → … → performance** so knowledge, people, choices, work, and memory remain connected.
