# SCN-088 — Reroute 30,000 People Before Confusion Becomes Panic

> **Universal pattern —** Move quickly from signal to qualification, responsibilities, and action.

> **Pattern family —** `PAT-16` Turn an incident into coordinated response

## Situation

Organizers must change access, signage, transportation, and communications within minutes while avoiding contradictory messages.

## What is usually lost

Conflicting signs and messages spread faster than the crowd can be rerouted.

## With Koali

Koali updates zones, transit, signage, and messages as one coordinated change, confirming each switch so the public receives one usable direction.

## Loop

`incident → zones → capacity → decisions → roles → communications → stabilization`

## Usage palette

respond · organize · act · verify · remember

## Component roles in this scenario

- **Kristal ●●●○○** — keeps the knowledge, provenance, relationships, and memory needed to understand the situation.
- **Konnaxion ●●○○○** — connects the people who can add, challenge, teach, learn, or interpret the shared context.
- **Orgo ●●●●●** — takes over when a check, decision, request, or intervention must become tracked work.

## What makes this characteristically Koali

The value is not any one isolated feature. It is preserving the same context across **incident → … → stabilization** so knowledge, people, choices, work, and memory remain connected.
