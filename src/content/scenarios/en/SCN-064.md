# SCN-064 — A bridge closes: medical products must be rerouted by tomorrow

> **Universal pattern —** Maintain a shared work state across people, teams, resources, and constraints.

> **Pattern family —** `PAT-14` Coordinate roles and dependencies

## Situation

Carriers, warehouses, customers, and inventory evolve throughout the crisis. The best route changes as new capacity appears or disappears.

## What is usually lost

Work often arrives without the why, the right context, its dependencies, or the expected proof of result.

## With Koali

Orgo coordinates roles and dependencies; Kristal maintains the shared state of needs, inventory, and decisions so competing versions of the plan do not emerge.

The Koali point is continuity: knowledge, people, decisions, work, and memory remain connected to the same context instead of being recreated in separate tools.

## Loop

`disruption → inventory → constraints → options → reassignments → deliveries → confirmation`

## Usage palette

understand · choose · organize · act · coordinate

## Component roles in this scenario

- **Kristal ●●●●○** — keeps the knowledge, provenance, relationships, and memory needed to understand the situation.
- **Konnaxion ●●●●○** — connects the people who can add, challenge, teach, learn, or interpret the shared context.
- **Orgo ●●●●●** — takes over when a check, decision, request, or intervention must become tracked work.

## What makes this characteristically Koali

The value is not any one isolated feature. It is preserving the same context across **disruption → … → confirmation** so knowledge, people, choices, work, and memory remain connected.

## Transferable to

logistics · health · industry

The domain changes; the pattern remains: **Maintain a shared work state across people, teams, resources, and constraints.**
