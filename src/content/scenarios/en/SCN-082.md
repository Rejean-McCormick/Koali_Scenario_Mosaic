# SCN-082 — An airline faces extreme weather, an IT outage, and crew shortages at the same time

> **Universal pattern —** Prevent teams from acting on different or outdated versions of reality.

> **Pattern family —** `PAT-17` Maintain a changing shared situation

## Situation

There is no longer a single "main problem." Every decision about one flight changes aircraft, crews, passengers, gates, and connections elsewhere.

## What is usually lost

Reality changes faster than shared context, so teams risk acting on different or outdated information.

## With Koali

Koali maintains an evolving shared state and prevents each operations center from optimizing its piece against a different version of reality.

The Koali point is continuity: knowledge, people, decisions, work, and memory remain connected to the same context instead of being recreated in separate tools.

## Loop

`events → shared situation → constraints → priorities → replanning → communications → recovery`

## Usage palette

respond · understand · organize · coordinate · remember

## Component roles in this scenario

- **Kristal ●●●●○** — keeps the knowledge, provenance, relationships, and memory needed to understand the situation.
- **Konnaxion ●●●○○** — connects the people who can add, challenge, teach, learn, or interpret the shared context.
- **Orgo ●●●●●** — takes over when a check, decision, request, or intervention must become tracked work.

## What makes this characteristically Koali

The value is not any one isolated feature. It is preserving the same context across **events → … → recovery** so knowledge, people, choices, work, and memory remain connected.

## Transferable to

transportation · large networks · operations

The domain changes; the pattern remains: **Prevent teams from acting on different or outdated versions of reality.**
