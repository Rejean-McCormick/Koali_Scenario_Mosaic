# SCN-035 — Ten Thousand People Write One Constitution

> **Universal pattern —** Keep needs, references, trade-offs, and versions connected throughout collective creation.

> **Pattern family —** `PAT-07` Co-create without losing the why

## Situation

Proposals branch, merge, oppose one another, and change wording. The challenge is not only to produce a final text, but to explain which problems each article was meant to solve and which objections remained open.

## What is usually lost

A final clause survives while the proposals, objections, and compromises that shaped it disappear.

## With Koali

Koali preserves the reasoning through branches, merges, and votes, so future citizens can understand the mandate and reopen it without starting from zero.

## Loop

`needs → proposals → arguments → versions → trade-offs → text → provenance`

## Usage palette

create · collaborate · choose · organize · remember

## Component roles in this scenario

- **Kristal ●●●●○** — keeps the knowledge, provenance, relationships, and memory needed to understand the situation.
- **Konnaxion ●●●●●** — connects the people who can add, challenge, teach, learn, or interpret the shared context.
- **Orgo ●●●○○** — takes over when a check, decision, request, or intervention must become tracked work.
- **UCKK ●○○○○** — supports learning and multimedia dissemination when the knowledge must reach a broader audience.

## What makes this characteristically Koali

The value is not any one isolated feature. It is preserving the same context across **needs → … → provenance** so knowledge, people, choices, work, and memory remain connected.

## Transferable to

governance · associations · open standards

The domain changes; the pattern remains: **Keep needs, references, trade-offs, and versions connected throughout collective creation.**
