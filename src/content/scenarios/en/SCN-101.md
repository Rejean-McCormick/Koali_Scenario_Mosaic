# SCN-101 — The same risks return under new names in every audit

> **Universal pattern —** Compare cases, seasons, incidents, or measures to detect recurrence and change.

> **Pattern family —** `PAT-20` See patterns over time

## Situation

Corrective actions, team changes, and rewording create the impression of progress. Multi-year analysis must connect causes, commitments, and actual results.

## What is usually lost

The result ends up in a report or in a few people’s memory instead of improving the next decision.

## With Koali

Koali follows actions beyond administrative closure and makes patterns visible across multiple audit cycles.

The Koali point is continuity: knowledge, people, decisions, work, and memory remain connected to the same context instead of being recreated in separate tools.

## Loop

`findings → actions → owners → results → recurrences → systemic cause`

## Usage palette

remember · organize · verify · act

## Component roles in this scenario

- **Kristal ●●●●○** — keeps the knowledge, provenance, relationships, and memory needed to understand the situation.
- **Konnaxion ●●○○○** — connects the people who can add, challenge, teach, learn, or interpret the shared context.
- **Orgo ●●●●●** — takes over when a check, decision, request, or intervention must become tracked work.

## What makes this characteristically Koali

The value is not any one isolated feature. It is preserving the same context across **findings → … → systemic cause** so knowledge, people, choices, work, and memory remain connected.

## Transferable to

audit · compliance · quality

The domain changes; the pattern remains: **Compare cases, seasons, incidents, or measures to detect recurrence and change.**
