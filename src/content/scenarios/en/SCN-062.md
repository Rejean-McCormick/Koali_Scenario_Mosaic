# SCN-062 — Move 400 Tons in the Only Safe Order

> **Universal pattern —** Maintain a shared work state across people, teams, resources, and constraints.

> **Pattern family —** `PAT-14` Coordinate roles and dependencies

## Situation

Cranes, trucks, closures, inspections, teams, and weather create a tight chain of dependencies. A small change must recalculate who is waiting for what and who needs to be notified.

## What is usually lost

One missed confirmation breaks the entire lifting sequence when dependencies live in separate schedules.

## With Koali

Koali gates every step with live commitments, weather, and proof of completion, exposing a broken dependency before the crane moves.

## Loop

`objective → roles → dependencies → windows → execution → updates → closure`

## Usage palette

organize · act · coordinate · verify

- **Kristal ●●●○○** — keeps the knowledge, provenance, relationships, and memory needed to understand the situation.
- **Konnaxion ●●●○○** — connects the people who can add, challenge, teach, learn, or interpret the shared context.

## What makes this characteristically Koali

The value is not any one isolated feature. It is preserving the same context across **objective → … → closure** so knowledge, people, choices, work, and memory remain connected.
