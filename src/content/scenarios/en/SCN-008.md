# SCN-008 — A crack appears on the 47th floor of an almost-new tower

> **Universal pattern —** Move from a symptom, signal, or anomaly to structured understanding.

> **Pattern family —** `PAT-01` Investigate a signal

## Situation

The developer, engineer, contractor, subcontractors, and manufacturer each hold different documents. A small visible anomaly must be connected to thousands of design decisions, substitutions, and inspections.

## What is usually lost

Context, sources, and hypotheses scatter before a usable understanding can form.

## With Koali

Koali makes it possible to trace the crack back through the choices and versions that might explain it, while keeping provenance and responsibilities distinct.

The Koali point is continuity: knowledge, people, decisions, work, and memory remain connected to the same context instead of being recreated in separate tools.

## Loop

`anomaly → plans → changes → materials → inspections → hypotheses → verification`

## Usage palette

understand · find · verify · act

- **Kristal ●●●●○** — keeps the knowledge, provenance, relationships, and memory needed to understand the situation.

## What makes this characteristically Koali

The value is not any one isolated feature. It is preserving the same context across **anomaly → … → verification** so knowledge, people, choices, work, and memory remain connected.
