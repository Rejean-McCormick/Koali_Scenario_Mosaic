# SCN-119 — A professional network stops publishing "best practices" without context

> **Universal pattern —** Render a knowledge base as courses, video, audio, guides, libraries, or channels.

> **Pattern family —** `PAT-23` Turn knowledge into media or learning

## Situation

Every practice states where it worked, for whom, under which constraints, with what evidence and failures. Members can create adapted branches instead of copying a universal recipe.

## What is usually lost

Once published, content often becomes detached from its sources, versions, and the people able to update it.

## With Koali

Kristal keeps the practice connected to its conditions; Konnaxion connects practitioners and critics; UCKK turns cases into reusable learning.

The Koali point is continuity: knowledge, people, decisions, work, and memory remain connected to the same context instead of being recreated in separate tools.

## Loop

`practice → context → evidence → publication → variants → feedback → evolution`

## Usage palette

collaborate · teach-share · disseminate · remember

## Component roles in this scenario

- **Kristal ●●●●●** — keeps the knowledge, provenance, relationships, and memory needed to understand the situation.
- **Konnaxion ●●●●●** — connects the people who can add, challenge, teach, learn, or interpret the shared context.
- **Orgo ●○○○○** — takes over when a check, decision, request, or intervention must become tracked work.
- **UCKK ●●●●●** — supports learning and multimedia dissemination when the knowledge must reach a broader audience.

## What makes this characteristically Koali

The value is not any one isolated feature. It is preserving the same context across **practice → … → evolution** so knowledge, people, choices, work, and memory remain connected.

## Transferable to

trades · health · industry

The domain changes; the pattern remains: **Render a knowledge base as courses, video, audio, guides, libraries, or channels.**
