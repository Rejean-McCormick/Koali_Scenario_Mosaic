# SCN-028 — A Language Returns First in Jokes, Songs, and Place Names

> **Universal pattern —** Preserve meaning and learning continuity when language, network access, or location changes.

> **Pattern family —** `PAT-06` Teach across language or connectivity constraints

## Situation

The community does not want to save only a dictionary. It connects words, pronunciations, stories, gestures, places, and culturally governed access levels so the language can live again in real use.

## What is usually lost

A dictionary preserves words but loses voice, place, gesture, permission, and living use.

## With Koali

Koali keeps each recording and variant inside its living context, so people can learn the language without flattening it through a dominant reference language.

## Loop

`word → voice → context → place → story → learning → new use`

## Usage palette

learn · teach-share · remember · disseminate

## What makes this characteristically Koali

The value is not any one isolated feature. It is preserving the same context across **word → … → new use** so knowledge, people, choices, work, and memory remain connected.
