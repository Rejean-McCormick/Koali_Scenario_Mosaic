# SCN-087 — The Network Fails as Another Public Emergency Begins

> **Universal pattern —** Prevent teams from acting on different or outdated versions of reality.

> **Pattern family —** `PAT-17` Maintain a changing shared situation

## Situation

Technical teams, emergency services, and authorities have different priorities but depend on the same degraded network. Information about what works changes minute by minute.

## What is usually lost

Technical recovery and public response collide because actors see different versions of the same degraded network.

## With Koali

Koali serves one governed incident view at the right access level, keeping decisions tied to the constraints actually known at the time.

## Loop

`outage → service map → priorities → repairs → temporary capabilities → recovery`

## Usage palette

respond · understand · collaborate · organize · coordinate

## Component roles in this scenario

- **Kristal ●●●●●** — keeps the knowledge, provenance, relationships, and memory needed to understand the situation.
- **Konnaxion ●●●●○** — connects the people who can add, challenge, teach, learn, or interpret the shared context.
- **Orgo ●●●●●** — takes over when a check, decision, request, or intervention must become tracked work.

## What makes this characteristically Koali

The value is not any one isolated feature. It is preserving the same context across **outage → … → recovery** so knowledge, people, choices, work, and memory remain connected.

## Transferable to

telecommunications · emergency response · infrastructure

The domain changes; the pattern remains: **Prevent teams from acting on different or outdated versions of reality.**
