# SCN-021 — Three Audiences, One Sacred Place, Different Permissions

> **Universal pattern —** Preserve meaning and learning continuity when language, network access, or location changes.

> **Pattern family —** `PAT-06` Teach across language or connectivity constraints

## Situation

The community wants to welcome people without revealing everything. Some stories are public, while others require a role, relationship, or permission; versions must also exist in several languages.

## What is usually lost

A single public version either exposes protected knowledge or strips the place of meaning.

## With Koali

Koali serves different authorized narratives from one governed knowledge base, welcoming each audience while preserving permissions and genuine differences between languages.

## Loop

`place → knowledge → audiences → access rules → languages → paths → understanding`

## Usage palette

understand · teach-share · disseminate

## Component roles in this scenario

- **Kristal ●●●●○** — keeps the knowledge, provenance, relationships, and memory needed to understand the situation.
- **Konnaxion ●●○○○** — connects the people who can add, challenge, teach, learn, or interpret the shared context.
- **UCKK ●●●●○** — supports learning and multimedia dissemination when the knowledge must reach a broader audience.

## What makes this characteristically Koali

The value is not any one isolated feature. It is preserving the same context across **place → … → understanding** so knowledge, people, choices, work, and memory remain connected.

## Transferable to

cultural tourism · heritage · education

The domain changes; the pattern remains: **Preserve meaning and learning continuity when language, network access, or location changes.**
