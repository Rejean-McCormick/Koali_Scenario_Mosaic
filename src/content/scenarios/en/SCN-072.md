# SCN-072 — Hide a 40-Person Reunion in Plain Sight

> **Universal pattern —** Give the responsible person the task, the why, the history, the constraints, and the expected evidence of completion.

> **Pattern family —** `PAT-13` Deliver work with its context

## Situation

The client is not just booking rooms: arrivals, surprises, meals, mobility, personal items, and information that some participants must not see too early all have to be synchronized.

## What is usually lost

The surprise depends on one concierge's memory when arrivals, permissions, mobility, and secret details are scattered.

## With Koali

Koali routes each detail only to the people who need it and updates them together, removing the single concierge’s memory as the point of failure.

## Loop

`request → constraints → roles → bookings → dependencies → confirmations → experience`

## Usage palette

organize · act · coordinate · remember

## Component roles in this scenario

- **Kristal ●●●○○** — keeps the knowledge, provenance, relationships, and memory needed to understand the situation.
- **Konnaxion ●●○○○** — connects the people who can add, challenge, teach, learn, or interpret the shared context.
- **Orgo ●●●●●** — takes over when a check, decision, request, or intervention must become tracked work.

## What makes this characteristically Koali

The value is not any one isolated feature. It is preserving the same context across **request → … → experience** so knowledge, people, choices, work, and memory remain connected.

## Transferable to

hospitality · private events · services

The domain changes; the pattern remains: **Give the responsible person the task, the why, the history, the constraints, and the expected evidence of completion.**
