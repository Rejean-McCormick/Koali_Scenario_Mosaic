# SCN-070 — A data center must replace a critical part without interrupting visible service

> **Universal pattern —** Turn an objective or project into tracked work and then into a verified result.

> **Pattern family —** `PAT-15` Carry a plan through execution

## Situation

The work itself is short, but preparation is enormous: dependencies, redundancy, windows, validations, rollback plan, and responsibilities must all be explicit.

## What is usually lost

Work often arrives without the why, the right context, its dependencies, or the expected proof of result.

## With Koali

Orgo requires the necessary preconditions and evidence before each step; Kristal preserves the technical context and risk decisions.

The Koali point is continuity: knowledge, people, decisions, work, and memory remain connected to the same context instead of being recreated in separate tools.

## Loop

`risk → plan → validations → dependencies → intervention → verification → closure`

## Usage palette

understand · organize · act · verify · remember

## Component roles in this scenario

- **Kristal ●●●●●** — keeps the knowledge, provenance, relationships, and memory needed to understand the situation.
- **Konnaxion ●●○○○** — connects the people who can add, challenge, teach, learn, or interpret the shared context.
- **Orgo ●●●●●** — takes over when a check, decision, request, or intervention must become tracked work.

## What makes this characteristically Koali

The value is not any one isolated feature. It is preserving the same context across **risk → … → closure** so knowledge, people, choices, work, and memory remain connected.

## Transferable to

digital infrastructure · energy · critical maintenance

The domain changes; the pattern remains: **Turn an objective or project into tracked work and then into a verified result.**
