# SCN-041 — Arctic-Proof, Compostable, Affordable: Pick Three

> **Universal pattern —** Connect exploration, design, testing, decisions, and the next operational step.

> **Pattern family —** `PAT-09` Move an idea to a prototype

## Situation

The team explores materials that must withstand cold, moisture, and transportation while reducing waste. Each prototype improves one criterion and sometimes worsens two others.

## What is usually lost

A rejected material is forgotten even when a later constraint change makes it the best option.

## With Koali

Koali remembers the tests and trade-offs behind the rejection, allowing the team to reopen a promising path without repeating the entire search.

## Loop

`constraints → ideas → materials → prototypes → tests → trade-offs → version`

## Usage palette

understand · collaborate · create · choose · organize

The value is not any one isolated feature. It is preserving the same context across **constraints → … → version** so knowledge, people, choices, work, and memory remain connected.
