# SCN-113 — The Annual Report That Refuses to Die as a PDF

> **Universal pattern —** Make knowledge or decisions understandable while retaining access to context and provenance.

> **Pattern family —** `PAT-22` Explain publicly without severing sources

## Situation

Every number, commitment, and project remains connected to sources, owners, decisions, and later updates. A reader can ask, "what became of this commitment six months later?"

## What is usually lost

A PDF freezes on publication day while commitments, owners, projects, and evidence keep changing.

## With Koali

Koali turns every number and commitment into a navigable live object tied to the work, letting the public watch a promise become—or fail to become—action.

## Loop

`data → commitments → narrative → publication → updates → public follow-up`

## Usage palette

remember · teach-share · disseminate

## Component roles in this scenario

- **Kristal ●●●●●** — keeps the knowledge, provenance, relationships, and memory needed to understand the situation.
- **Konnaxion ●●●○○** — connects the people who can add, challenge, teach, learn, or interpret the shared context.
- **Orgo ●○○○○** — takes over when a check, decision, request, or intervention must become tracked work.
- **UCKK ●●●●●** — supports learning and multimedia dissemination when the knowledge must reach a broader audience.

## What makes this characteristically Koali

The value is not any one isolated feature. It is preserving the same context across **data → … → public follow-up** so knowledge, people, choices, work, and memory remain connected.

## Transferable to

companies · NGOs · public administration

The domain changes; the pattern remains: **Make knowledge or decisions understandable while retaining access to context and provenance.**
