# SCN-010 — Users turn an ordinary tool into something its creators never imagined

> **Universal pattern —** Move from a symptom, signal, or anomaly to structured understanding.

> **Pattern family —** `PAT-01` Investigate a signal

## Situation

A secondary feature suddenly becomes the product's main use. The team must understand the real needs behind this repurposing rather than merely counting clicks.

## What is usually lost

Context, sources, and hypotheses scatter before a usable understanding can form.

## With Koali

Koali connects usage data, conversations, expressed needs, and product decisions so the reason behind the next evolution is preserved.

The Koali point is continuity: knowledge, people, decisions, work, and memory remain connected to the same context instead of being recreated in separate tools.

## Loop

`unexpected use → behaviors → testimonials → needs → hypotheses → prototypes → learning`

## Usage palette

find · understand · collaborate · create · choose

## Component roles in this scenario

- **Kristal ●●●●○** — keeps the knowledge, provenance, relationships, and memory needed to understand the situation.
- **Konnaxion ●●●●●** — connects the people who can add, challenge, teach, learn, or interpret the shared context.
- **Orgo ●●○○○** — takes over when a check, decision, request, or intervention must become tracked work.

## What makes this characteristically Koali

The value is not any one isolated feature. It is preserving the same context across **unexpected use → … → learning** so knowledge, people, choices, work, and memory remain connected.
