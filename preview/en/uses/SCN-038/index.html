SCN-038 · Collaborate & Create

Distinguish documented reconstruction, memory, and new proposal

Koali distinguishes documented reconstruction, memory, and new proposal; it lets descendants and experts work in the same context. The continuity goal is to keep needs, references, trade-offs, and versions connected throughout collective creation. In this example, the context stays connected across: traces → memory → map → versions → proposals → co-design → revival.

ExampleDescendants of an abandoned village try to bring it back without inventing a fake past
