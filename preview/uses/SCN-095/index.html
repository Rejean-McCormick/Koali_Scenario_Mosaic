# SCN-095 — A laboratory wants to make an experiment reproducible

> **Universal pattern —** Make knowledge, method, and evidence reproducible when people change roles or leave.

> **Pattern family —** `PAT-21` Preserve capability beyond individuals

## Situation

A laboratory wants to make an experiment reproducible. Important capability must remain reproducible even when the original expert, team, or project is no longer present.

## What is usually lost

The result ends up in a report or in a few people’s memory instead of improving the next decision.

## With Koali

Kristal keeps the relevant knowledge objects, sources, history, relationships, versions, and evidence connected. Konnaxion lets the relevant people discover one another, contribute context, learn, discuss, or co-create around those same objects. Orgo turns the resulting need, decision, or intervention into routed work with responsibilities, dependencies, evidence, and closure. UCKK can turn validated knowledge or experience into learning and multimedia dissemination for the appropriate audience.

## Loop

`question → protocol → versions → data → result → reusable package`

## Usage palette

remember · understand · teach-share · verify

- **Kristal ●●●●●** — keeps the knowledge, provenance, relationships, and memory needed to understand the situation.
